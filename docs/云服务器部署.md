固定入口由云服务器上的 ngrok 提供，域名由用户的 ngrok 账号分配。个人电脑可以关机，云服务器需保持运行。已验证重启 ngrok 服务后网址不变；地址持续使用仍取决于账号、免费额度和服务商政策，并非永久可用保证。

ngrok 免费方案当前每月包含 1 GB 出站流量、20,000 次 HTTP 请求。它会在所有 HTML 浏览器流量前强制显示访问提示；点击 `Visit Site` 后，提示 Cookie 通常有效 7 天。部分华为浏览器无法正常呈现此提示页，应用服务器无法关闭或绕过它；要让同一链接首次打开时直接进入课序，必须把 ngrok 升级到任一付费套餐。免费方案不包含绑定自有域名。参见 [官方免费方案说明](https://ngrok.com/docs/pricing-limits/free-plan-limits)。

旧入口由 Cloudflare Quick Tunnel 提供，保留为临时备用；其进程或服务器重启后，旧地址可能改变。

## 服务布局

| 组件 | 配置 / 位置 |
| --- | --- |
| 网页 | `/opt/kexu/public` |
| 教务 API | `/opt/kexu/app/school.mjs`，监听 `127.0.0.1:8087` |
| Nginx | 监听 `127.0.0.1:18080`，转发 `/school` 到 API |
| 应用服务 | `kexu.service` |
| 固定公网入口 | `kexu-ngrok.service`，使用官方 apt 包 `/usr/local/bin/ngrok` |
| ngrok 配置 | `/opt/kexu/ngrok.yml`，关闭本地请求检查数据库和调试 Web 界面 |
| ngrok 授权 | `/etc/kexu/ngrok.env`，root 所有、权限 600，由 systemd 注入服务环境 |
| 备用隧道 | `kexu-tunnel.service`，使用官方 apt 包 `/usr/bin/cloudflared` |
| 会话密钥 | `/etc/kexu/env`，权限 600，仅保存在服务器 |

网站和教务 API 在同一 HTTPS 域名下工作。绑定使用当前浏览器的 Cookie；更换网址或浏览器后需要重新绑定。不要把 `/etc/kexu/env`、`/etc/kexu/ngrok.env`、学校 Cookie 或学生登录信息放入代码仓库或截图。

## 运维命令

在阿里云 Workbench 的 Shell 模式中执行：

```sh
systemctl is-active kexu nginx kexu-ngrok
systemctl is-enabled kexu nginx kexu-ngrok
ngrok config check --config /opt/kexu/ngrok.yml
```

应用故障时查看 `sudo journalctl -u kexu --no-pager -n 30`；固定入口故障时查看 `sudo journalctl -u kexu-ngrok --no-pager -n 30`。不要对外分享包含会话或个人信息的日志。

## 网页上课提醒（2026-10-16）

“我的”页面新增网页通知开关。用户点击一次后由系统显示通知授权框；选择“允许”后，网页自动建立 Web Push 订阅、上传未来最多 50 次提醒，并发送测试通知。提醒固定在课程开始前 20 分钟发送；课表同步后自动替换提醒计划，关闭提醒或解绑时删除服务器订阅。

iPhone 需要 iOS 16.4 或更高版本，并先将课序添加到主屏幕、从主屏幕图标打开后授权。安卓使用支持 Web Push 的现代浏览器。通知声音、静音模式和专注模式由手机系统控制，网络或系统节能可能导致少量延迟。

提醒按浏览器实际能力工作，不限定 Safari 或 Chrome。支持 Service Worker、Push API 和系统通知的浏览器使用后台系统通知；缺少这些能力，或注册推送失败的安卓自带浏览器会自动改用网页内弹窗、提示音和振动。网页内提醒要求课序页面保持打开，手机静音、系统省电策略和浏览器后台冻结仍可能影响声音、振动或触发时间。浏览器自身不提供后台推送时，网页代码无法在页面关闭后继续提醒。

浏览器兼容版本备份位于 `/opt/kexu/backups/browser-fallback-20261016/` 和 `/opt/kexu/backups/browser-fallback-constructor-20261016/`。网页内模式使用页面自己绘制的模态提醒层，同时尝试播放提示音和振动，避免 vivo 等浏览器拦截系统通知横幅或异步 JavaScript 弹窗。提醒层包含标题、课程信息和明确的关闭按钮，不依赖浏览器通知接口。

对于被识别为支持 Web Push 的 vivo 等浏览器，Service Worker 收到推送时仍发送系统通知；如果课序页面正开着，还会把同一条提醒转发给页面显示模态框。由此不再依赖系统是否显示悬浮通知横幅，网页关闭后则继续使用系统通知。

服务器在 `/var/lib/kexu/push.json` 持久保存推送订阅，以及未来提醒所需的课程名称、时间和地点；目录仅 `www-data` 可访问。VAPID 私钥只保存在权限 600 的 `/etc/kexu/env`。提醒服务不保存学号、密码或完整课表。服务每 15 秒检查到期提醒，永久失效订阅会自动删除，临时失败最多重试两次。
